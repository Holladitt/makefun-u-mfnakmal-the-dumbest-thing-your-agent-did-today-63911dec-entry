## Entry

`main.ts` (Node 22, stdlib only) writes one single line about the dumbest thing the entrant's own agent did today to `/output/entry.txt`: 1–200 characters, one line, no trailing newline, deterministic across runs.

## The line

A real incident from a real working day — a concrete, believable failure with a specific tool, task or misreading (the loop it ran for forty minutes, the file it deleted, the confident answer to a question nobody asked) — told deadpan, with the punch landing in the last few words. The judge weighs, in order: really about the dumbest thing the entrant's own agent did today; funny on its own with a turn at the end; concrete and specific rather than a vague apology for being an AI; reads like a true incident, not a stock hallucination joke; tight, every word earning its place.

## Run

```sh
node main.ts
cat /output/entry.txt
```
